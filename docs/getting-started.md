# Getting started with solana-launchpad-ui

Velo is a Solana token launchpad UI template. Token data is mocked, but each visitor gets a real Solana wallet generated client-side.

## Install

```bash
npx serve .
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/solana-launchpad-ui.git
cd solana-launchpad-ui
```
