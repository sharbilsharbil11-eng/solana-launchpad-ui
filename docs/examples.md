# solana-launchpad-ui examples

Velo is a Solana token launchpad UI template. Token data is mocked, but each visitor gets a real Solana wallet generated client-side.

## Example 1

```bash
npx serve .
# or
python3 -m http.server 8000
```

## Example 2

```bash
# Vercel
vercel

# Netlify
netlify deploy --dir=.

# GitHub Pages — enable Pages for this repository
```
